身份组

把多个账号入口映射到同一份玩家数据。卡片之间可以拖拽组合。

data UUID 是什么？为什么它和账号 UUID 不一样？

账号 UUID 是玩家登录时使用的身份：正版 UUID 由 Mojang 分配，离线 UUID 由“OfflinePlayer:名称”计算。一个组最多各放一个正版/离线入口。身份组按 UUID 匹配，不按名字；同一个名字的正版 UUID 和离线 UUID 是两个不同的值，所以离线 UUID 不能拖进正版区域，正版 UUID 也不能拖进离线区域。

data UUID 是玩家数据的存储钥匙，对应 identity/playerdata/<data>.dat。它不是登录账号，所以同一把 data UUID 可以被多个组复用；复用后这些组会共享同一份背包/位置/进度。

“生成 data UUID”得到的是空白钥匙：还没有绑定任何账号，所以池子里显示为“空白 data”。把正版/离线账号映射进组、玩家上线并同步后，数据才会写进这把钥匙。池子里的“正版数据 / 离线数据”候选是用账号 UUID 当数据键，名字直接来自账号，避免出现不知道是谁的 data。

已有组修改 data UUID 时，会自动弹出重绑确认：程序先备份旧数据与目标数据，再按你选择的策略复制或保留，避免玩家进度丢失。新组没有旧数据，直接设置即可。

未进组 / 数据 UUID 库

账号和 data 分开显示：正版、离线、data 各自独立。把账号拖进卡片的“正版/离线”区域，把 data UUID 拖进“数据”区域。正版/离线只能在一个组；data 可以复制到多个组。
