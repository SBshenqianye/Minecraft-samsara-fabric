# samsara · 实现状态与已知缺口

> 状态：v3.8（2026-10-31）
> 定位：**缺口登记册**。记录「设计要求了、代码尚未实现或未达标」的条目，以及「文档陈述与代码事实不符」的条目。
>
> **登记原则**：**意图**以《需求文档》《设计文档》为准（用户可见行为以需求优先，纯技术方案以设计优先）；**事实**以代码为准。
> 《需求文档》《设计文档》保持设计原意不变，不把设计降级成"现状描述"；代码与设计的差额集中登记在本文件。
> 因此本文件是**唯一**可以出现"未实现/未达标"判定的地方——正文文档需要读者知道实现现状时，只放指向本文件的指针。
>
> 配套：[`需求文档.md`](需求文档.md)（做什么）· [`设计文档.md`](设计文档.md)（怎么做）· [`设计规范.md`](设计规范.md)（代码规范）· [`decisions/`](decisions/)（为什么）
