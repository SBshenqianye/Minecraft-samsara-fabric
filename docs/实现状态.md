## 3b. 文档自相矛盾（⚠ 待裁决）

《设计文档》〈旗帜多边形圈地〉的**「旗帜朝向（FACING）旋转校正」表内部自相矛盾**，直接影响 8 方向旋转的实现——按字面实现会得到与设计意图相反的结果，因此需裁决后再动手。

**表格原文（`FACING` / 旋转次数 / 效果）：**

| FACING | 表里的"旋转次数" | 表里的"效果" |
|---|---|---|
| north | 0 | 不旋转 |
| north_east | 7×45°=315° | `ts`→东 |
| east | 6×45°=270° | `ts`→东 |
| south_east | 5×45°=225° | `ts`→东南 |
| south | 4×45°=180° | `ts`→南 |
| south_west | 3×45°=135° | `ts`→西南 |
| west | 2×45°=90° | `ts`→西 |
| north_west | 1×45°=45° | `ts`→西北 |

**矛盾点：**

1. **次数列方向反了**：表头说"按 45° 递增**顺时针**旋转"，但 north_east（从 north 顺时针 45°）却写 7 次，east 写 6 次…… 递减。这一列等于 `8 − 顺时针步数`。
2. **次数列与"效果"列冲突**：以 `ts`（顶条纹，local 前方）在世界坐标上的投影为准，
   **取「顺时针步数 = 0/1/2/3/4/5/6/7」**（north→NE→E→SE→S→SW→W→NW）时：
   north→north、north_east→东北、east→**东**、south_east→**东南**、south→**南**、
   south_west→**西南**、west→**西**、north_west→**西北**——
   **6 行与"效果"列完全吻合**（east / south_east / south / south_west / west / north_west），
   只有两处不符：`north_east` 行（应为"东北"，却写"东"）与次数列本身。
3. **与旧项目实现对照**：`old-project/…/pojo/Extension.java` 的 8 方向循环移位序列
   `Up→RightUp→Right→RightDown→Down→LeftDown→Left→LeftUp→Up` 正是**标准 45° 顺时针**，
   即 north=0 步、north_east=1 步 …… north_west=7 步，同样支持上述第 2 点。

**倾向结论（待用户确认后实施）**：采用 **顺时针步数 `north=0, north_east=1, east=2, south_east=3, south=4, south_west=5, west=6, north_west=7`**；
表中"旋转次数"列整体作废、`north_east` 行的"效果"立方格按"东北"更正。斜向图案的"观看者↔纹章学"换算沿用已确认的**双轴反转（180°）**规则：
观看者前左 → 纹章学 `downRight`、前右 → `downLeft`、后左 → `upRight`、后右 → `upLeft`；
斜向条纹（`stripe_downleft`/`stripe_downright`）与 `cross`/`straight_cross`/`border` 在该反转下**保持不变**（点对称）。
