## 关键决策

1. **容器索引范围**：索引所有 `Container` 方块实体，但只持久化非空容器；空容器在内存中保留位置与槽位数，重启后随区块加载恢复。
2. **分片粒度**：按维度 + region（32×32 区块）一个 JSON，避免单文件过大，也避免每区块一个文件的碎片。
3. **离线玩家数据只读**：只读 `MinecraftServer.getWorldPath(PLAYER_DATA_DIR)` 下的 `.dat`，按 mtime+size 缓存，绝不写回。
4. **保险扫描顺序**：在线玩家背包/末影箱 → 离线玩家（可配）→ 乐透池/滚存/基金/待领取 → 当前维度已加载容器与掉落物 → 容器索引缓存（可配）→ 其他维度（可配）。任一命中即拒绝。
5. **容器写入**：只接受管理端 token（`ops` scope），写入前创建容器审计快照；revision 不匹配返回 409；只加载目标区块，不做批量强制加载。
6. **Vue 迁移**：复杂页面保留原有命令式逻辑，用 Vue 组件 `onMounted/onUnmounted` 包装；共享状态用 composables，不引入 Pinia/TypeScript/UI 框架。
