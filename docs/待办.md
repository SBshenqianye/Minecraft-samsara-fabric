> 5. **“本轮不做”不是拉黑**：任何条目都可能在以后重新立项，只要届时补上验收标准。

| 状态 | 含义 |
|---|---|
| `TODO` | 已确认存在，未开工 |
| `DOING` | 正在改（同一时间只允许一条） |
| `WAIT` | 需要用户拍板（文档 vs 代码谁对、或是否立项） |
| `DONE` | 已修并有验证证据 |
| `DROPPED` | 用户明确取消（需写明日期与说法） |
