## 1. 项目定位

原版红石生存服务器的**世界生命周期管理**（Fabric 服务端模组 `samsara`/周目管理 + 数据包 + 离线工具）。
三大主题：**空间**（区块圈地/备份/重生成）· **时间**（周目轮回/新出生点/活跃度）· **逆熵**（时间倒流/玩偶影像）。

- 设计灵感/事实来源：`docs/周目系统设计文档.md`（16 章，里程碑 M0~M9，**唯一事实来源，先读这个**）
- 代码规范/长期记忆：`docs/设计规范.md`（命名/输出/分页/确认/单例/权限/26.x API/数据安全）

## 3. 功能清单

| 模块 | 命令 | 权限 |
|---|---|---|
| 周目状态机 | `/season status [页码]` `/season info` | status/info 所有人 |
| 周目管理 | `/season create <名> [模式]` `/season start` `/season end` | 管理（OP level 2+） |
| 分组重排 | `/season respawn-groups`（围绕当前周目中心重分组+传送） | 管理（OP level 2+） |
| 世界信息 | `/season info`（种子+出生点） | 所有人 |
| 调试工具 | `/samsara debug status/json/reload/reset/create/settime/fakeplayers/groups/flow/diff/rewind/claim/config/whitelist` | 服主（OP level 4） |

- 状态机：`PENDING →(start)→ ACTIVE →(end)→ ENDED →(未来)→ ARCHIVED`
- 持久化：`config/samsara/season.json`（Gson，含 settings）、`rewind.json`（倒流时刻表）、`whitelist.json`（配置白名单）
- 命令完整参数参考见 `mod/README.md`；数据文件在 **`test-server/config/samsara/`**；M2 倒流物理删除备份在 `test-server/config/samsara/backups/purge_<时间戳>/`（不落存档目录）

## 4. 代码结构

```
mod/src/main/java/com/shenqianye/samsara/
├── Samsara.java              # 入口（server entrypoint；tick/停服/加入事件钩子）
├── command/
│   ├── SeasonCommand.java    # /season（含 info、respawn-groups）
│   └── DebugCommand.java     # /samsara debug（fakeplayers 注入/groups 预览/rewind 控制/whitelist）
├── season/
│   ├── Season.java           # 周目模型（§3.3：spawnCenter/groupSpawns）
│   ├── SeasonData.java       # season.json 根结构（含 settings）
│   ├── SeasonManager.java    # 单例状态机 + 持久化 + M2 分组/传送/广播 + setTime
│   ├── GroupPlanner.java     # 分组算法（纯逻辑，可单测）
│   ├── PlayerRegistry.java   # 注册玩家合并 + 测试注入池（单例）
│   └── SpawnCenterCalculator.java # 出生中心计算（纯逻辑）
├── whitelist/                # WhitelistData/Store + ChunkProtector（倒流保护集）
└── rewind/                   # RewindData/McaRegion（MCA 读写）/RewindEngine（档2/档3 调度+完成即自动删块+停服兜底）/Tier3Restore/DiffStore/DiffRecorder
```

架构要点：
- **服务端模组**：`environment "*"` + `server` entrypoint → 服务器只装即可用；客户端装了单人可用；客户端连服零副作用。
- **Manager 一律单例**（曾有多实例不同步 bug，见设计规范 §6）。
- **26.2 存档结构**：主世界区块在 `world/dimensions/minecraft/overworld/{region,entities,poi}/`（非旧 `world/region/`），McaRegion 用维度根。

## 6. 环境 / 工具链（本机）

| 项 | 位置 |
|---|---|
| JDK 25 | 沙箱会话临时：`C:\Users\Administrator\AppData\Local\Temp\dsh-<会话> \jdk25\jdk-25.0.4+7`（新会话按需从微软/华为镜像重装到可写目录） |
| Gradle 9.5.1 | 镜像下载（services.gradle.org 在此网络不可达）；GRADLE_USER_HOME 需指向**可写**目录 |
| 构建 | `gradle build`（JAVA_HOME=JDK25，GRADLE_USER_HOME=可写目录） |
| RCON 工具 | 小端序协议客户端（26.x RCON 已改为小端），会话内临时编译 |
| fabric-installer | 本沙箱不可用（它强制用 Windows 证书库 WINDOWS-ROOT，被沙箱封锁），生产服按官方同构手工组装 |
