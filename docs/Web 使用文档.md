# samsara · Web 使用文档（非技术管理员）

> 面向服主/管理员，不讲代码。接口细节见 [`Web API.md`](Web%20API.md)，实现现状见 [`实现状态.md`](实现状态.md)。
> 管理端默认只监听本机：`http://127.0.0.1:8720/`（测试服 `8722`）。用户只读页：`http://127.0.0.1:8720/user`。

## 1. 第一次打开

1. 启动服务器（推荐 `tools/start-headless.ps1`，无窗口、日志重定向）。
2. 控制台会打印 Web 地址和 token；也可以看 `config/samsara/web.yml` 的 `web.token`。
3. 浏览器打开 `http://127.0.0.1:8720/`，在置顶弹窗粘贴 token。
4. token 只保存在当前浏览器会话；关闭浏览器后需要重新输入。**不要把 token 发给玩家**。

如果页面一直显示骨架屏：token 不对、服务器没启动 Web、或端口被占用。看控制台 WARN 和 `config/samsara/web.yml`。

## 2. 页面结构

顶部两个大类：

- **samsara**：模组自己的功能。
- **本体**：原版服务器配置、存档备份、RCON 控制台、Web 审计。

`samsara` 下按用途分三组：

| 分组 | 标签 | 用途 |
|---|---|---|
| 配置 | 配置、圈地范围、输出格式、权限 | 改规则、改提示文本、改权限 |
| 信息展示 | 地图 | 看世界、玩家、实体、圈地、出生点 |
| 业务信息 | 身份组、世界栈 | 玩家身份映射、周目/世界层管理 |

大部分页面右上角有“重新读取 / 保存并重载”。改完点保存，失败会在字段下方或顶部提示原因。

## 3. 配置页

- 左侧是分组导航，右侧是表单；带“重启”标记的项需要重启服务器才生效。
- `track.retention.curve` 是坐标系曲线：直接拖动圆点，横向是年龄（天），纵向是保留比例；右键或 Delete 删除档位。
- 圈地范围页的 3×3 罗盘：箭头是射线方向，正中间“▣”是“边框”。全边框默认只选边框，颜色距离 2 就是 5×5 的周长（不填内部）；内部由多面旗帜射线闭合后填充。调试画布的“闭合填充”开关可切换原始线段/闭合结果。
- 调试画布可放置多面旗帜、拖动、旋转、删除；它只做预览，不改真实世界。

## 4. 地图页

- **世界栈总览**：每个栈一层，主世界在上、下界在下、末地在右；栈顶显示在最上面。
- 点击面板进入详细地图；滚轮缩放、空白拖动平移。
- 玩家标记是头像 pin（只显示头部）；点击可复制 TP 命令。
- 详细地图可点选实时玩家/实体：右侧显示名字、类型、坐标、生命；选中轨迹高亮，悬浮弱高亮。
- “在线玩家与最近方块操作”面板显示**已加载区块内**的在线玩家、最近发言和最近破坏/放置；不是全服日志。
- 图层开关：玩家、实体、轨迹、保护区块、出生点、排斥半径。

## 5. 世界栈页

- 每张卡片是一层世界；栈顶在上、`stack_0` 在最下。
- 可以上传卡片图片（PNG/JPEG/WebP，自动压缩）、恢复默认、归档栈层、查看操作时间线。
- 新建/切换世界层属于高风险操作，先备份；具体命令见 [`模组使用文档.md`](模组使用文档.md)。

## 6. 本体页

- **服务器配置**：编辑 `server.properties` 常用项，保存后按提示重启。
- **存档备份**：创建备份、查看备份列表；世界数据回滚优先用世界栈时间线/本体备份。
- **RCON 控制台**：在服务器线程执行命令并把输出显示在页面。快捷命令按“服务器 / 世界 / 玩家 / 诊断 / 危险”分组；`stop` 会停服，需要二次确认。
- **Web 审计**：每次管理端写操作前自动快照配置；可预览并回滚。审计不包含完整世界存档。

## 7. 回看与轨迹（游戏内）

Web 只负责配置保留策略。实际回看在游戏里：

```text
/samsara track view <玩家> [开始时间] [--speed 1] [--duration 10m]
```

拖动模式：**按住 Ctrl**，W/S 前后、Shift 加速、空格暂停；松开 Ctrl 退出。非拖动模式空格/Shift 仍是正常飞行/潜行。聊天栏没有“拖动”按钮。

## 8. 用户只读页 `/user`

- 不需要 token；只显示公开信息：在线人数、版本、MOTD、世界栈、地图、玩家位置、最近发言。
- 不显示 UUID、生命、朝向、token、文件路径、旗帜主人。
- 如果要公开到公网，只反向代理 `/user`、`/user.js`、`/map.js`、`/banners.js`、`/style.css`、`/api/user/*`；**不要**转发管理端 `/api/*`。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 401 / 一直要求 token | token 复制错、`web.yml` 改过但没重启、或浏览器禁用了 sessionStorage |
| 地图空白 | 服务器没加载对应区块；先让玩家上线或 `forceload` |
| 头像显示首字母 | 离线/无正版皮肤，或 Mojang 网络不可达；属正常回退 |
| 保存后没生效 | 看字段是否标“重启”；配置类通常热重载，端口/世界层需要重启 |
| 玩家看不到发言记录 | 发言在进入轨迹后才会写入 `.evt`；实时层只保留最近 120 条 |

## 经济业务（乐透 / 基金 / 保险）

管理端“业务信息 → 经济业务”标签（原生面板，直接调用 `/api/lottery`，不套 iframe）：顶部指标卡显示开关、模式、可下注日、统计日、实时死亡数、票数、奖池与基金；下方按“当前轮次 / 物品价值表 / 服务器基金 / 保险 / 历史开奖”分区，使用与管理端其他页面一致的 panel、指标卡和列表。物品价值表同时显示中文名、英文名与 ID，支持中文、全拼、首字母和逐字前缀搜索（如 `zuanshi`、`zs`、`zshi`），可按分类筛选、按价值或名称排序；固定表头、默认先渲染 200 行。方块类物品使用预渲染的 3D 等距图标，缺少平面材质的头颅用中文首字占位。原始 JSON 收进“原始 JSON（调试用）”折叠区。可手动开奖/取消退款（二次确认）。公开用户端 `/user` 显示奖池、票数、开奖时间、基金实物列表、保险聚合计数（不显示保单主人）、上期脱敏结果和公开物品价值表，不显示实时死亡数。

物品保险在同一页/命令中：主手单件投保，保费从副手扣除（价值 × 2）；理赔前会扫描本人/在线玩家/周围容器与掉落物，原物还在时拒绝；大额理赔进管理员审核。
