## 4. Web 模块地图

| 文件 | 职责 |
|---|---|
| `web-src/` | Vue 3 + Vue Router + Vite 源码；构建到 `web/vue/` |
| `app.js` | 旧管理端路由、导航、连接、配置主页（Vue 兼容层按需加载） |
| `page-kit.js` | 页面生命周期与作用域清理 |
| `announcements.js` | 公告页（生命周期试点） |
| `server.js` | 本体配置、RCON、审计 |
| `identity.js` | 身份组、data UUID、白名单 |
| `lottery.js` | 经济业务：乐透/基金/保险 |
| `config-editor.js` | PageSpec/FormSpec 配置编辑器 |
| `map.js` / `world-stack.js` | 地图与世界栈 |
| `output.js` / `permissions.js` | 输出模板与权限 |
| `form-kit.js` / `item-ui.js` / `value-table.js` | 公共组件 |

后端入口：

- `web/LocalWebServer.java`：路由与鉴权
- `web/*WebService.java`：各业务 API
- `lottery/`：乐透、金价、物品估值
- `insurance/`：保险与理赔
- `container/`：容器索引、离线玩家只读扫描
- `identity/`：身份组与数据工具

## 5. 改动原则

1. 一次只动一个页面/模块，改完跑 E2E。
2. 新页面使用 `mount/unmount/buildNav + ctx.scope`。
3. 旧页面不强制迁移；下次改到它时顺手迁移。
4. 不引入前端框架和 npm 依赖，除非有明确的单页试点。
5. 公共组件优先于复制粘贴。
6. 所有文本用 `textContent`，禁止 `innerHTML`。
7. 涉及物品/经济改动必须同时考虑基金、奖池、保险、待领取四个位置。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 切换 tab 后导航不换 | 页面是否调用 `buildNav`；是否注册了生命周期 |
| 公告页没有导航 | 正常，公告页不构建全局导航，侧栏应隐藏 |
| 审计页卡顿 | 列表已限制最近 100 条；检查快照数量 |
| 金价不更新 | `gold.syncEnabled`、`config/samsara/gold-price.json`、接口可达性 |
| 领奖掉地上 | 应走 `addToInventory`/待领取，不应调用 `player.drop` |
| 版本号不变 | 改 `WebVersion.VALUE`（Web）或 `gradle.properties` 的 `mod_version`（模组） |
| Vue 页面 404/空白 | 先 `cd web-src && npm.cmd run build`，确认 `mod/src/main/resources/web/vue/` 有产物且已打进 jar |
| 容器页列表空 | 目标区块未加载；让玩家靠近/`forceload` 后点“刷新索引”，未加载区块只读缓存 |

## 7. 维护节奏建议

- 优先修回归和安全问题，少加新系统。
- 每个版本只做 1-2 个主题，避免一次改太多。
- 大功能先写“能否回滚/如何验证”，再动手。
- 维护精力不足时，冻结新功能，只保留修复和文档更新。
