# ADR-005: 命令谦让策略

> 日期：2026-09-07
> 状态：已采纳
> 关联：《设计文档》〈命令规范〉；写入《设计规范》〈权限约定〉

## 背景

samsara 的命令需要与其他模组共存。如果别名冲突，需要决定谁优先。

## 决策

**命令谦让（yield on conflict）**：

- 所有命令以 `/samsara` 开头为全名
- 所有命令均有去掉 `/samsara` 前缀的短别名
- 启动时检测别名是否已被其他模组注册
- 已注册 → samsara 不抢占，仅保留 `/samsara` 前缀版本
- 未注册 → 注册别名供玩家使用

**含义**：samsara 不霸道，优先让位给玩家已习惯的其他模组命令。`/samsara <command>` 始终可用作保底。
