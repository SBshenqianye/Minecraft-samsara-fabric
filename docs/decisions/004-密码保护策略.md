# ADR-004: 密码保护策略

> 日期：2026-09-07
> 状态：已采纳
> 关联：《设计文档》〈密码保护与命令〉

## 背景

离线模式下无认证，需要自行实现身份验证。考虑过依赖 EasyAuth mod，但为了最小依赖原则，决定自包含实现。

## 决策

### 密码策略可配置

```json
{
  "password": {
    "minLength": 8,
    "storageMode": "hashed",
    "allowChange": true,
    "allowShort": false
  }
}
```

### 未注册/登录处理

以观察者模式传送到栈底世界（worldStack[0]），聊天提示注册/登录命令。

### 密码继承

- canonical 密码 = 组默认密码
- 新 alias 自动继承 canonical 密码，无需注册
- alias 可设置独立密码覆盖

### 登录流量限制

- 单玩家限流：5 次/分钟
- 指数退避：10s → 20s → 40s → 80s → 160s
- 临时封禁：连续 10 次失败 → 封禁 15 分钟
- IP 限流：10 次/分钟（同 IP）
