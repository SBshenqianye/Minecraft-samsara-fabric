# samsara · 模组使用文档（含指令）

> 面向服主与管理员。Web 页面操作见 [`Web 使用文档.md`](Web%20使用文档.md)；接口见 [`Web API.md`](Web%20API.md)。
> 所有指令都以 `/samsara` 为根；部分短别名在其他模组未占用时自动注册。

## 1. 安装与启动

1. 服务器需要 **Minecraft 26.3 + Fabric Loader 0.20.1 + Java 25**。
2. 把 `samsara-<版本>.jar` 放进 `mods/`；依赖已通过 JiJ 打包，无需另装 SnakeYAML。
3. 首次启动生成：
   - `config/samsara/*.yml`：配置（commands、permissions、claim-range、claim-particles、storage、web、output）
   - 存档内 `samsara/`：世界数据（claims、track、diff、season 等）
4. Web 管理端默认 `127.0.0.1:8720`，token 在 `config/samsara/web.yml`（控制台也会打印）。Web 入口是 Vue 3 + Vite 构建产物（`/vue/`），管理端 `/`、公开端 `/user`、容器页 `/containers` 同一应用；旧页面壳保留在 `/legacy.html`。管理端为左侧顶级工作区（本体 / samsara / 其他模组）+ 二级 Tab。
5. 容器索引数据在 `world/samsara/containers/`（按维度 + region 分片），可随存档备份；删除后下次区块加载会重建。
6. 玩家背包 Web 写入：在线玩家直接改内存背包；离线玩家进入 `world/samsara/inventory-pending/` 安全队列，玩家登录后下一 tick 或停服保存前应用。不要手工编辑队列文件；离线写入会校验 `DataVersion`。

## 2. 配置速查

| 文件 | 作用 | 热重载 |
|---|---|---|
| `commands.yml` | 命令开关、回看、拖动、自瞄、轨迹保留、关服倒计时、栈间传送缓降 | `/samsara debug reload` |
| `permissions.yml` | 命令路径权限等级、owner 名单、停用节点 | 保存即生效 |
| `claim-range.yml` | 圈地距离、图案方向（含 `center`） | 保存后 `recomputeAll` |
| `claim-particles.yml` | 圈地边界粒子 | 保存即生效 |
| `storage.yml` | 全局数据是否跟随存档 | 保存时迁移 |
| `web.yml` | Web 开关/端口/token | 重启 Web 服务 |
| `lottery.yml` | 死人乐透开关、日模式、开奖/截止、票价、抽成、统计口径 | `/samsara lottery reload` |
| `insurance.yml` | 物品保险开关、保费倍数、保单天数、理赔冷却/上限、扫描半径、离线玩家/其他维度/容器索引开关 | `/samsara debug reload` |
| `output.yml` | 游戏内提示模板 | 保存即生效 |

关键项：

```yaml
view:
  scrub:
    enabled: true          # 允许按住 Ctrl 拖动
  aim:
    enabled: false
    mode: snap             # snap=快速对准，smooth=平滑转动
    hz: 5                  # snap 每秒对准次数（2~20）
track:
  retention:
    mode: curve            # adaptive / keepAll / curve
    curve:
      - ageDays: 7
        keepRatio: 1.0
      - ageDays: 30
        keepRatio: 0.5
      - ageDays: 0
        keepRatio: 0.1
chain:
  voidDropSlowFalling: true
  voidDropSlowFallingSeconds: 60
```

## 3. 常用指令

### 3.1 信息与诊断

| 指令 | 说明 |
|---|---|
| `/samsara help` | 帮助与可点击入口 |
| `/samsara version` | 模组版本 |
| `/samsara tps` / `/samsara mspt` | 服务器性能 |
| `/samsara where [broadcast]` | 当前维度/坐标/区块/朝向；`broadcast` 全服广播（有冷却） |
| `/samsara info` | 周目/世界栈概况 |
| `/samsara debug reload` | 重读 `commands.yml` 等可热重载配置 |
| `/samsara debug report` | 诊断报告（若当前版本提供） |

### 3.2 周目与世界栈

| 指令 | 说明 |
|---|---|
| `/samsara season status` | 当前周目状态 |
| `/samsara season advance [same\|new]` | 发起全员同意制周目推进 |
| `/samsara season agree` / `cancel` / `vote-status` | 同意、撤回、查看投票 |
| `/samsara world list` / `info` / `enter <层>` / `leave` | 世界栈浏览与切换 |
| `/samsara reset new [种子] [类型] [archiveData]` | 生成新世界并入栈（高风险，先备份） |
| `/samsara restart [秒]` | 公告倒计时后优雅停服（默认 10 秒） |

### 3.3 圈地

| 指令 | 说明 |
|---|---|
| `/samsara claim list` | 列出全部圈地节点 |
| `/samsara claim info` | 查看当前/指向的圈地 |
| `/samsara claim rebuild` | 按当前配置重建保护白名单 |
| `/samsara claim scan` | 扫描已放置旗帜并注册 |
| `/samsara claim give <方向> <距离>` | 调试用：直接生成指定方向的保护 |
| `/samsara claim remove <x> <z>` | 移除节点（需确认） |

图案方向：`north/northeast/east/southeast/south/southwest/west/northwest/center`。`center` = 边框：按图案颜色距离画 (2d+1)² 正方形周长（颜色 = 边框半径），不填充内部；全边框默认只选它。内部由多面旗帜的射线闭合后填充。

### 3.4 轨迹与回看

| 指令 | 说明 |
|---|---|
| `/samsara track list [玩家]` | 列出轨迹时段 |
| `/samsara track view <玩家> [开始时间] [选项]` | 只读回看 |
| `/samsara track view pause\|resume\|stop\|status` | 控制回看 |
| `/samsara track view seek <时间\|±Ns\|N%>` | 跳转 |
| `/samsara track view aim [on\|off]` | 自瞄开关 |
| `/samsara track view speed <倍率>` / `reverse` | 倍速/倒放 |
| `/samsara track view scrub [on\|off]` | 是否允许拖动模式 |
| `/samsara track replay <玩家> ...` / `stop` / `status` | 回放（会生成人偶，可被捕捉） |
| `/samsara track sweep` | 立即执行保留清理 |
| `/samsara camera start <玩家> <开始时间> [--duration 30m --speed 4 --dim <维度> --radius <区块> --chunk <x> <z> --no-track --no-diff]` | 统一镜头：默认同时回看轨迹与方块 Diff；`--no-track` / `--no-diff` 单独关闭。`--chunk`/`--fixed` 固定 Diff 焦点，人偶离开焦点会隐藏；不指定时 Diff 跟随人偶所在区块 |
| `/samsara camera stop\|status\|pause\|resume\|seek\|speed` | 同时控制轨迹与 Diff 回看；`stop` 幂等；原有 `track view` / `diff view` 仍可单独使用 |

回看操作键：

- **按住 Ctrl** 进入拖动模式；W/S 前后、Shift 加速、空格暂停；松开 Ctrl 退出。
- 非拖动模式空格/Shift 仍是飞行/潜行，不会被拖动模式占用。
- 回看中右键人偶可翻页查看只读背包。

轨迹文件：`<存档>/samsara/track/<世界>/cycle<id>/<日期>/<uuid>.bin` 与同名 `.evt`。发言记录写在 `.evt` 的 `TYPE_CHAT`；Web 实时层另保留最近 120 条。

挂机降采样：`commands.yml` 的 `track.idle.enabled`（默认 true）、`track.idle.afterSeconds`（默认 10 秒）、`track.idle.heartbeatSeconds`（默认 60 秒）。位置/朝向/状态长时间不变时不再写 5Hz 位置样本，但仍保留骨架点、登录/退出、换维度、聊天与装备/动作等事件；`.bin/.evt` 格式不变，回看与保留策略无需改动。

活动分档采样：`track.adaptive.enabled`（默认 true）、`track.adaptive.moveHz`（默认 3）、`track.adaptive.combatHz`（默认 5）、`track.adaptive.combatWindowMs`（默认 3000）。纯移动按 moveHz、攻击/使用/骑乘按 combatHz、静止按 idle 心跳；`adaptive=false` 恢复固定 `track.sampleHz`。装备/背包/攻击/使用/聊天仍只在变化或发生时写 `.evt`，不会随采样率重复。

| `/samsara identity ...` | 身份组/账号映射（Web 身份组页更直观） |
| `/samsara tpa <玩家>` / `tpahere <玩家>` | 传送请求 |
| `/samsara tpaccept` / `tpdeny` / `tpcancel` | 接受/拒绝/取消 |

### 3.6 权限

| 指令 | 说明 |
|---|---|
| `/samsara perm info <路径>` | 查看实际等级 |
| `/samsara perm set <路径> <等级>` | 设置（user/op/config/owner/deny） |
| `/samsara perm reset <路径>` | 恢复默认 |

`deny` 连控制台也拒绝，只有恢复路径（`perm`、`config`、`web`、`debug perm/config/reload`）保留控制台入口。

### 3.7 OP / owner 登录（离线服）

只对**离线登录且名字在 `ops.json` 或 `permissions.yml` 的 `owners` 里**的玩家生效；普通玩家完全不受影响。目的不是识别身份，而是防止别人用受保护名字进服后直接拿到 OP/owner 命令。

| 指令 | 说明 |
|---|---|
| `/reg <注册码> <密码> <密码>` | 首次注册；密码至少 8 位，必须输两遍 |
| `/l <密码>` | 以后每次进服登录 |
| `/samsara register ...` / `/samsara login ...` | 全名；短别名被其他登录插件占用时用这个 |
| `/samsara opauth code <名字>` | 后台/owner 生成一次性注册码（30 分钟、用一次失效） |
| `/samsara opauth reset <名字>` | 清除旧密码并生成新注册码 |
| `/samsara opauth list` | 查看受保护账号与待登录人数 |

- 登录前除 `/l`、`/reg`、`/login`、`/register`、`/help` 外，所有命令都会被拦下；120 秒未登录会被踢出。
- 注册码只出现一次（在生成它的控制台/RCON/owner 聊天里），不要公开。
- 凭据保存在 `config/samsara/op-auth.yml`，只存 PBKDF2 哈希；重置会作废旧密码。
- 短别名 `/reg`、`/l` 按“命令谦让”注册；已存在同名根节点时自动让位，只保留 `/samsara` 全名。

## 4. 栈间传送规则

| 方向 | 触发 | 落点 |
|---|---|---|
| 主世界虚空 → 同层下界 | `y < minY - 32` | `(x/8, z/8)` 安全地面 |
| 下界虚空 → 下层主世界 | `y < minY - 32` | `(x*8, z*8)` 高空（约 304），缓降 |
| 下界顶部 → 同层主世界 | `y > 255` | `(x*8, z*8)` **最底层安全位置** |
| 主世界顶部 → 上层下界 | 主世界 `y > 建筑限制 + 5`（26.3 为 325） | `(x/8, z/8)` **最底层安全位置**，不落到下界屋顶 |

- 所有跨世界/跨栈传送清空 `fallDistance`，并用 `Relative.DELTA` **保留动量**（水平与垂直）。
- 栈底下界虚空交给原版死亡；不会无限往下传。
- 目标层未加载时会自动按 5s→10s→20s→40s→60s 重试；`world list/info` 显示失败原因。

## 5. 备份与回滚

- 世界数据：世界栈时间线、本体备份（`backups/`）。
- Web 可管理的小文件：本体 → Web 审计，每次写请求前自动快照，可预览/回滚。
- 删除方块/区域前的安全备份：`backups/delete_<时间>/` + 同名 `.zip`。

## 6. 故障排查

| 现象 | 排查 |
|---|---|
| `claim` 范围不对 | 确认 `claim-range.yml` 的 `patternDirections.<pattern>` 含 `center`；保存后看 Web 调试画布；再 `/samsara claim rebuild` |
| 跨栈传送失败 | `world list` 看目标层加载失败原因；`debug retrystack` 立即重试 |
| 回看无法拖动 | `view.scrub.enabled` 是否为 true；是否按住 Ctrl；是否在 PAUSED/PLAYING 状态 |
| 自瞄仍晕 | 确认 `view.aim.mode=snap`；降低/提高 `view.aim.hz`（2~5 更稳，10~20 更跟手） |
| 轨迹占空间过大 | Web 配置页拖曲线；或 `track.retention.mode=adaptive`；`track sweep` 立即清理 |
| Web 打不开 | `web.yml` 的 enabled/port；端口占用看 WARN；token 是否正确 |

## 7. 死人乐透

| 指令 | 说明 |
|---|---|
| `/samsara lottery status` | 奖池、票数、结算日、开奖/截止时间、我的票 |
| `/samsara lottery bet <人数> [张数] [--exact]` | 默认只估值，不扣物品；显示主手价值、最多可买几张、将消耗物品、超额和下注后奖池，点聊天里的「确认下注」才执行 |
| `/samsara lottery bet confirm` / `cancel` | 确认/取消最近一次下注报价；报价 60 秒过期，确认时重新校验主手 |
| `/samsara lottery bet now <人数> [张数] [--exact]` | 快速通道：跳过估值，直接按主手扣物品买票 |
| `/samsara lottery collect` | 领取待领取奖金 |
| `/samsara lottery list [页]` | 历史开奖 |
| `/samsara lottery value <物品>` | 查询物品价值（VP） |
| `/samsara lottery gold [set <USD/oz>]` | 查看国际金价与金块/金锭/金粒估值；管理员可手动覆盖 |
| `/samsara lottery draw` / `cancel` / `reload` / `fund` | 管理员：手动开奖/取消退款/重载/基金 |
| `/samsara lottery insure` | 主手单件物品投保；保费从副手扣除（价值 × 2） |
| `/samsara lottery insure entity` | 靠近 6 格内的已驯服/命名生物投保；死亡 3 秒后在主人身边复活 |
| `/samsara lottery insurance list` / `claim [id]` | 查看保单 / 理赔；原物还在、或在乐透下注池/滚存/基金/待领取时拒绝；下注消耗过的保单标记为 VOID |
| `/samsara lottery insurance pending` / `approve <id>` | 管理员：待审核理赔 / 审核通过 |

默认每游戏日一轮：结算日 00:00 截止（盲押），次日 07:00 开奖；精准匹配，按中奖票平分，5% 进 fund，无人中滚存。统计玩家/村民/命名怪，全维度全栈层；公开 Web 不显示实时死亡数。

每轮开始时可按 `seed.percent`（默认 10%，上限 `seed.maxValue` 默认 512 VP）从 fund 抽取初始奖池；取消/流局时未使用的种子退回基金。`gold.syncEnabled`（默认关闭，生产服开启）是国际金价总开关：开启后仅金粒、金锭、金块、金压力板（2 金锭）按国际金价缩放；金苹果、金胡萝卜、金工具/护甲等含非金材料，不参与。国际金价默认每 6 小时从 `api.gold-api.com/price/XAU` 拉取，以 `gold.baseBlockValue`（默认 36 VP）为金块锚点，按当前价相对 `gold.referenceUsdPerOunce`（默认 4000）缩放；金锭 = 金块/9，金粒 = 金块/81，不直接按 1 m³ 黄金的真实质量换算。
